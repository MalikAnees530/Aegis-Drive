# Security Policy

## Supported Versions
We currently support the latest version of Aegis Drive for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not open a public issue for security vulnerabilities.**

Report privately through GitHub's **[Security Advisories](https://github.com/MalikAnees530/Aegis-Drive/security/advisories/new)** — use **"Report a vulnerability"** on the repository's **Security** tab. We aim to acknowledge reports within 72 hours and will keep you informed throughout remediation.
