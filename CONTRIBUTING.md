# Contributing to Aegis Drive

Thank you for your interest in contributing to Aegis Drive! As a student-led project, we value all feedback and contributions.

## How to Contribute
1. **Report Bugs**: Use the Issues tab to report any bugs or unexpected behavior.
2. **Suggest Features**: Have an idea for the AI model or navigation system? Open an issue!
3. **Submit Code**: 
   - Fork the repository.
   - Create a feature branch (`git checkout -b feature/your-feature`).
   - Commit your changes.
   - Push to the branch.
   - Open a Pull Request.

## Code Standards
- Follow standard Kotlin coding conventions.
- Test any CameraX or MediaPipe changes on a physical device before submitting.
- Match the **dark-first "Premium Minimal"** design system: reference the shared design tokens and styles (`res/values/`, `res/values-night/`, `AegisMotion`) instead of hardcoding colors, sizes, or fonts.
